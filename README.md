# P5 Créez et utilisez une base de données immobilière avec SQL

## Contexte

Laplace Immo est un réseau national d'agences immobilières. Dans le cadre du projet DATAImmo, l'entreprise veut mieux comprendre le marché pour prévoir le prix de vente des biens.
J'ai modifié et créé la base de données des transactions immobilières en France, puis je l'ai utilisée pour analyser le marché.

## Objectifs

- Documenter les données dans un dictionnaire des données
- Mettre à jour le schéma relationnel en 3e forme normale
- Vérifier la conformité des données avec le RGPD
- Créer la base, charger les données et contrôler leur intégrité
- Répondre aux questions des agences avec des requêtes SQL

## Réalisations

- Analyse de trois sources de données (valeurs foncières DVF, recensement INSEE, référentiel géographique data.gouv)
- Dictionnaire des données conforme au RGPD
- Schéma relationnel normalisé avec clés primaires et étrangères
- Préparation des fichiers CSV et chargement dans la base
- Contrôle du nombre de lignes après chargement
- Requêtes SQL avancées avec jointures, agrégations, sous-requêtes et alias

## Outils

SQL, SQLite, Excel

## Compétences

- Modéliser une base de données en 3e forme normale
- Créer des tables avec leurs contraintes et leurs relations
- Écrire des requêtes SQL avancées
- Prendre en compte le RGPD dans la gestion des données
